# Glossary

> Stub. Define domain and Shopify terms as they come up.

Seed terms:
- **OS 2.0** — Shopify Online Store 2.0 theme architecture (JSON templates, sections everywhere).
- **Dawn** — Shopify's reference/default theme; this project's base.
- **Section / Block** — merchant-editable layout unit / repeatable item within a section.
- **Metafield / Metaobject** — structured custom data attached to a resource / standalone reusable content entity.
- **Section Rendering API** — endpoint to re-render a section's HTML (used for live filtering).
- **Search & Discovery** — Shopify app providing filter/facet configuration.
