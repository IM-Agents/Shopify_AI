# Sections & Components Plan

## Required Reusable Sections

### Announcement Bar

Settings:
- Text / rich text
- Link URL
- Background and text colors
- Visibility controls
- Optional rotating messages

### Header + Mega Menu

Settings and behavior:
- Logo upload and width
- Main menu selection
- Mega menu blocks by top-level item
- Promotional image/content blocks
- Sticky header option
- Mobile drawer navigation
- Keyboard-accessible dropdowns

### Hero Banner

Settings:
- Desktop/mobile images
- Heading, subheading, rich text
- Button label/link/style
- Text alignment and overlay options
- Responsive image focal point

### Featured Collection

Settings:
- Collection picker
- Product count
- Card layout
- CTA settings
- Responsive grid columns

### Featured Products

Settings:
- Manual product picker or dynamic source
- Product count
- Card display options
- Quick add toggle if needed

### Image With Text

Settings:
- Image/video
- Heading, content, CTA
- Layout direction
- Background color
- Spacing controls

### Testimonials

Settings:
- Static blocks or metaobject source
- Rating, quote, author, avatar
- Slider/grid layout

### FAQ / Accordion

Settings:
- Question and answer blocks
- Optional metaobject source
- Default open/closed behavior
- Accessible keyboard support

### Tabs

Settings:
- Tab title/content blocks
- Dynamic product metafield support
- Mobile stacking behavior

### Newsletter

Settings:
- Heading, body text
- Shopify customer form integration
- Consent/help text
- Background and image options

### Footer

Settings:
- Logo
- Menu groups
- Newsletter toggle
- Social links
- Payment icons
- Copyright text

## Key Snippets

- Responsive image helper
- Product card
- Collection card
- Variant badge / inventory badge
- Price display wrapper
- Button component
- Icon renderer
- Review/rating display if review app is approved
- Tracking event helper placeholders

## Component Quality Requirements

- Responsive across mobile, tablet, laptop, and desktop.
- Works with missing images and long text.
- Supports keyboard navigation where interactive.
- Avoids duplicate markup and duplicate style blocks.
- Uses semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`) where appropriate.
- Provides alt text, labels, and accessible names.
